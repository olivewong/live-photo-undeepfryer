# live photo undeepfryer

live photo -> raw, undeepfried png frames. runs entirely in the browser, nothing gets uploaded.

feed it the original .mov from apple's "export unmodified original" ([how](https://support.apple.com/en-us/111762)) and it pulls every frame out as a png.

live: https://olivewong.github.io/live-photo-undeepfryer/

## run locally

open `index.html` in a browser. no build step.
